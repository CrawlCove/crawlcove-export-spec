# Changelog

## 1.0.0 — 2026-09-24

Initial release, matching `EXPORT_SCHEMA_VERSION` in the Crawl Cove desktop
app (`crawl-cove-app`, `src/shared/report/buildJson.ts`).

- `schema/crawl-export.schema.json` — JSON Schema (2020-12) for the full-crawl
  JSON export.
- `docs/csv-columns.md` — column reference for the equivalent CSV export.
- `docs/versioning.md` — how `schemaVersion` changes.
- `examples/sample-crawl-export.json` — a real export, generated by the app's
  own export code against a small seeded crawl (7 pages covering the common
  cases: healthy page, missing meta description, 404, redirect, an overlong
  title, a noindexed page, and a fetch timeout).
- `scripts/validate.js` — Ajv-based validator; CI runs it against the sample
  on every push.
